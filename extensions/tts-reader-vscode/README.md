# Lector TTS para VS Code

Lee en voz alta texto seleccionado o copiado usando la voz local del sistema. Es útil para escuchar respuestas de asistentes como Copilot o Codex: copia una respuesta y ejecuta el comando de portapapeles.

## Comandos

- **Lector TTS: Leer texto seleccionado** (`Ctrl+Alt+R`)
- **Lector TTS: Leer texto copiado** (`Ctrl+Alt+Shift+R`)
- **Lector TTS: Detener lectura** (`Ctrl+Alt+.`)

En Linux usa `espeak-ng`; en macOS usa `say`; y en Windows usa la voz integrada de PowerShell.
